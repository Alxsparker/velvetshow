Datenschutzerklärung

Zuletzt aktualisiert: 1. November 2026

Velvet Show und Velvet Remote erheben, übertragen oder speichern keine personenbezogenen Daten. Es ist kein Konto erforderlich. Keine Analysen. Kein Tracking.

Velvet Show — macOS

Velvet Show ist eine macOS-Anwendung, die vollständig auf deinem lokalen Rechner läuft. Sie liest aus einer lokalen SQLite-Datenbank (ShowBuddy) und speichert alle eigenen Daten in einer lokalen JSON-Datei auf deinem Mac.

  • Es werden keine Daten an einen Server gesendet.
  • Es sind keine Analysen und keine Absturzberichte aktiviert.
  • Es ist weder ein Konto noch eine Registrierung erforderlich.
  • Die App fragt den Zugriff auf deinen lokalen Ordner mit Audiodateien an (macOS-Sandbox) — dieser Zugriff bleibt auf deinem Gerät.

Velvet Remote — iPhone & iPad

Velvet Remote ist eine Begleit-App für Velvet Show. Sie kommuniziert ausschließlich mit Velvet Show auf einem Mac in deinem lokalen Netzwerk oder per USB-Kabel.

  • Es werden keine Daten an einen externen Server gesendet.
  • Es werden keine personenbezogenen Informationen erhoben oder gespeichert.
  • Es ist weder ein Konto noch eine Registrierung erforderlich.
  • Die App nutzt die Berechtigung „Lokales Netzwerk“, um Velvet Show über Bonjour in deinem lokalen Netzwerk zu finden. Diese Berechtigung dient ausschließlich der Geräteerkennung und überträgt keine personenbezogenen Daten.
  • Der Name des zuletzt verbundenen Servers wird lokal auf dem Gerät gespeichert, um die automatische Wiederverbindung zu ermöglichen. Diese Information verlässt dein Gerät nie.

Velvet Light DJ — macOS

Velvet Light DJ folgt der DJ-Software, die du bereits nutzt, und sendet Licht-Cues an deine MaestroDMX-Box. Es gibt kein Konto, keine Analysen, keine Absturzberichte und keine Werbung. Fast alles bleibt auf deinem Mac und in deinem lokalen Netzwerk. Drei Dinge nutzen das Internet:

  • Lizenzprüfung (Lemon Squeezy). Um eine Lizenz zu aktivieren, zu prüfen oder freizugeben, sendet die App deinen Lizenzschlüssel und den Namen deines Macs (den du in den Systemeinstellungen gewählt hast) an Lemon Squeezy, unseren Zahlungsanbieter. So wird ein Schlüssel auf zwei Macs begrenzt. Der Schlüssel wird im macOS-Schlüsselbund gespeichert.
  • Update-Prüfung (GitHub). Etwa alle sechs Stunden fragt die App bei GitHub nach, ob eine neuere Version existiert. GitHub sieht deine IP-Adresse, wie jede Website, die du besuchst; die App sendet sonst nichts außer ihrer Versionsnummer.
  • Käufe werden vollständig von Lemon Squeezy abgewickelt, nicht von uns. Wir sehen deine Kartendaten nie.

Auf deinem eigenen Rechner und in deinem eigenen Netzwerk:

  • Die App liest den Verlauf deiner DJ-Software (djay, Serato DJ, VirtualDJ) im schreibgeschützten Modus. Sie schreibt nie etwas hinein, und deine Musikdateien werden nur lokal analysiert.
  • Um Pause, Zurückspulen und Überspringen in djay zu verfolgen, liest die App die auf dem Bildschirm angezeigte Zeit von djay über die macOS-Berechtigung „Bedienungshilfen“, die du selbst erteilst. Nichts, was auf diese Weise gelesen wird, verlässt deinen Mac.
  • Die App spricht nur mit deiner MaestroDMX-Box in deinem lokalen Netzwerk (Cue-Nummern, Cue-Namen, Lichtfarben).
  • Die Einstellungen der App, das Startdatum der Testversion und das, was sie aus deinen Entscheidungen gelernt hat, werden auf deinem Mac gespeichert.
