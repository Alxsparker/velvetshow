Dans l'ordre d'un show

Une app après l'autre

Chaque app a son rôle. Voici les réglages utiles, dans l'ordre d'un show. Les noms entre guillemets sont ceux des boutons dans les apps.

Étape · 1

Velvet Visualizer

  1. Rien à brancher pour l'aperçu. Il marche sans aucun matériel : un aperçu 3D sur le Mac.
  2. Importez votre show MaestroDMX : menu Fichier ▸ « Importer un fichier MaestroDMX… », puis choisissez le fichier JSON exporté de votre Maestro. Les projecteurs, leurs adresses et les groupes sont placés pour vous.
  3. Pour voir la vraie lumière : dans MaestroDMX (version 1.5 ou plus récente), activez l'envoi d'Art-Net. Le Mac et le boîtier doivent être sur le même réseau.
  4. Allumez l'interrupteur « Live DMX » de la barre d'outils. Quand le voyant est vert, la vue 3D suit ce que le boîtier envoie.

Étape · 2

EzQuiel

EzQuiel règle le son de la salle, sur iPhone ou iPad (App Store). Il est pensé pour les tables Allen & Heath CQ.

  • Le lien avec la lumière : la table doit envoyer du son à l'entrée ligne du boîtier, sinon il n'écoute rien.
  • Pour relier l'app à la table et régler le son, voir l'aide d'EzQuiel.

Étape · 3

Velvet Show

  1. Importez vos cues : dans les réglages, « Import MaestroDMX → OSC Library » lit un fichier de show ou de sauvegarde MaestroDMX et crée les événements OSC.
  2. Réglez l'envoi OSC : « OSC Host » est l'adresse du boîtier. Le port est 7672, celui de MaestroDMX tel qu'il sort de la boîte. Vous n'avez rien à changer, sauf si vous avez modifié le port du boîtier.
  3. Testez : « OSC Test (raw) » envoie un message d'essai au boîtier, sans toucher à vos cues.
  4. Posez vos cues sur la timeline du morceau, au bon moment. Velvet Show les déclenche en MIDI ou en OSC.
  5. Velvet Remote (iPhone, iPad) sert de télécommande, et la lecture automatique peut enchaîner les morceaux.

Étape · 4

Velvet Light DJ

  1. Ouvrez les réglages (le troisième onglet). « Adresse pour les cues (OSC) » est l'adresse du boîtier. « Port OSC » est 7672 par défaut. « Adresse pour lire les noms des cues » permet à l'app de lire les cues de votre boîtier.
  2. Autorisez l'Accessibilité quand macOS le demande : c'est ce qui permet à l'app de suivre la position dans djay. Sans elle, l'app compte le temps toute seule.
  3. Allumez « Lumières auto ». Elle démarre en pause : rien ne part tant que vous ne l'activez pas.
  4. Lancez un morceau dans djay. L'app choisit la cue qui va avec. Pour la corriger, utilisez le menu « Ambiance de ce morceau ».
  5. N'utilisez pas Velvet Show en même temps : les deux enverraient des cues au boîtier.

Velvet Light DJ est fait pour MaestroDMX uniquement.
